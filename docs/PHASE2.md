# 二期任务规划（Phase 2）

> 更新日期：2026-08-17
> 备注：本次已根据实际代码完成度更新任务状态，大部分任务已在后续迭代中实现。

---

## 1. 目标

在一期 MVP 的基础上，补齐英语学习的关键能力，提升用户体验：
1. 实现写作练习与 AI 语法纠错
2. 提供更自然的发音训练（TTS 标准发音 + 跟读评分）
3. 每日话题自动生成与推送
4. 更丰富的学习数据分析与可视化
5. 优化 UI/UX，提升产品完整度

---

## 2. 范围边界

### 2.1 本期包含
- 写作练习模块（题目生成、AI 批改、语法纠错展示）
- AI 对话陪练（自由对话、场景模拟）
- TTS 语音合成播放标准发音
- 每日话题自动生成与历史话题管理
- 学习进度可视化（能力雷达图、趋势曲线）
- 学习数据导入导出增强（Word 报告、JSON 备份）
- 错误复习与薄弱点专项训练

### 2.2 本期不包含
- 用户登录与云端同步
- 多语言界面
- 学习社群/排行榜
- 移动端 App
- 真题模拟考试时间训练

## 4. 任务清单

### 任务 1：写作练习模块
**目标**：让用户根据目标与级别完成写作练习，并获得 AI 语法纠错。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 1.1 写作题目生成 | 根据 target + level 生成议论文/看图写话/邮件等题目 | ✅ |
| 1.2 写作输入页面 | 计时器、字数统计、提交按钮 | ✅ |
| 1.3 AI 批改 API | `/api/ai/write`：语法纠错、结构评分、总分 | ✅ |
| 1.4 批改结果展示 | 错误高亮、正确表达、评分展示 | ✅ |
| 1.5 保存练习记录 | 写入 store，自动保存到 `static/` | ✅ |

**验收标准**：
- 用户能根据目标获得匹配难度的写作题目。
- AI 批改结果包含：语法错误、修改建议、结构评分、总分。
- 写作记录能保存并展示在 Progress 页面。

---

### 任务 2：AI 对话陪练
**目标**：提供自由对话和场景模拟，提升口语交际能力。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 2.1 对话页面 | 类聊天界面，显示用户和 AI 的对话记录 | ✅ |
| 2.2 AI 角色选择 | 根据目标选择不同角色（考官、面试官、朋友等） | ✅ |
| 2.3 语音/文字输入 | 支持语音输入和文字输入 | ✅ |
| 2.4 对话上下文管理 | 维护多轮对话历史，让 AI 能连续对话 | ✅ |
| 2.5 纠错与提示 | AI 在对话中给出表达优化建议 | ✅ |

**验收标准**：
- 用户能与 AI 进行多轮对话。
- AI 能根据目标人群调整对话场景和语气。
- 支持语音和文字两种输入方式。

---

### 任务 3：TTS 标准发音与跟读
**目标**：帮助用户纠正发音，提供标准发音示范。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 3.1 TTS 播放 | 使用 Web Speech API 播放标准发音 | ✅ |
| 3.2 跟读模式 | 用户跟读后，对比识别结果与标准文本 | ✅ |
| 3.3 发音评分 | 基于识别相似度给出发音评分 | ✅ |
| 3.4 慢速播放 | 支持 0.5x、0.75x、1x 播放速度 | ✅ |

**验收标准**：
- 能播放题目/参考答案的标准发音。
- 用户跟读后有相似度评分。
- 支持调整播放速度。

---

### 任务 4：每日话题自动生成与管理
**目标**：让系统每天自动生成适合的练习话题，并支持历史回看。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 4.1 话题生成策略 | 根据日期、目标、级别生成不同话题 | ✅ |
| 4.2 话题缓存 | 同一天同一用户返回相同话题 | ✅ |
| 4.3 历史话题 | 支持查看过去的话题和练习记录 | ✅ |
| 4.4 话题收藏 | 用户可收藏喜欢的话题 | ✅ |
| 4.5 话题推送 | 首页展示今日话题提醒 | ✅ |

**验收标准**：
- 每天首次进入口语练习时，自动生成新话题。
- 同一天重复进入，话题不变。
- 用户能查看历史话题记录。

## 8. 风险与应对

| 风险 | 应对措施 |
|------|----------|
| TTS 浏览器兼容性差 | 提供文字版发音提示，使用多种 TTS 引擎 |
| AI 对话上下文过长 | 限制对话轮数，定期总结上下文 |
| 图表库体积大 | 按需加载，或使用轻量图表库 |
| Word 报告样式复杂 | 先实现基础样式，后续迭代美化 |
| 专项练习生成质量不稳定 | 用 Prompt 模板约束，人工校验 |
