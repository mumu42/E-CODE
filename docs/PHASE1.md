# 一期任务规划（Phase 1：MVP）

---

## 1. 目标

完成一个可运行的最小可用版本（MVP），让用户能够：
1. 选择学习目标并完成级别测定
2. 进行每日口语练习并获得 AI 反馈
3. 将学习记录保存到项目 `static/` 文件夹
4. 从 `static/` 文件夹或本地文件导入历史学习记录

---

## 2. 范围边界

### 2.1 本期包含
- 项目初始化与环境搭建
- 本地文件存储与读取能力（`static/` 文件夹）
- 用户 Onboarding 流程
- 每日口语练习（核心功能）
- 学习进度查看

### 2.2 本期不包含
- 写作练习（放到二期）
- AI 语音对话陪练
- 多语言界面
- 用户登录与云端同步
- 复杂的能力雷达图

---

## 3. 需求变更记录

在 Phase 1 执行过程中，根据实际需求对以下内容进行了调整：

| 变更项 | 原计划 | 变更后 |
|--------|--------|--------|
| AI 平台 | Anthropic / OpenAI | **阿里云百炼（BaiLian）Anthropic 兼容接口** |
| AI 平台扩展 | 单一 AI 平台 | **支持多平台切换：DeepSeek / Kimi / GLM / Claude / Gemini / GPT / BaiLian** |
| 文件导出 | 浏览器下载 `.xlsx` | **保存到项目 `static/` 文件夹**，同时保留下载功能 |
| 文件导入 | 仅本地文件选择 | 新增 **从 `static/` 文件夹选择导入** |
| 自动保存 | 手动导出 | **完成测评/练习后自动保存到 `static/`** |
| 新增 API | 2 个 AI 路由 | 新增 3 个文件路由：`/api/files/save` / `/api/files/list` / `/api/files/read` |

## 8. 风险与应对

| 风险 | 应对措施 |
|------|----------|
| Web Speech API 浏览器兼容性 | 提供文字输入降级方案 |
| AI 接口响应慢 | 添加加载态和超时重试 |
| AI 返回格式不稳定 | 前端做容错解析，必要时展示原文 |
| static 文件夹需要本地运行 | 本地 `npm run dev` 使用，不支持静态部署 |
| 用户没有 AI API Key | 在环境变量中配置， onboarding 前检测 |
