# 五期任务规划（Phase 5）

> 更新日期：2026-08-21
> 备注：Phase 4 已全部完成，本期在已有本地私有 AI 学习闭环基础上扩展阅读、听力、词汇、全真模考等核心模块。

---

## 1. 目标

在四期已完成的多档案、AI 纠错、错题游戏化、本地文件管理、设置中心基础上，横向扩展更多题型与深度学习场景，打造更完整的英语综合能力训练平台：

1. **阅读与听力专项训练**：覆盖英语学习中除口语/写作外的输入型技能。
2. **词汇本与间隔重复**：将错题、生词自动沉淀为可复习的词汇资产。
3. **全真模考与成绩预测**：整合各题型，提供限时模考与目标达成预测。
4. **AI 学习顾问**：随时解答英语知识点、讲解错题、给出学习建议。
5. **数据洞察与离线体验**：更强的学习预测、周报月报与离线可用性。

---

## 2. 范围边界

### 2.1 本期包含

- AI 生成阅读理解文章与题目
- 听力理解训练（填空 / 选择 / 听写）
- 个人词汇本 + 基于 SM-2 的闪卡复习
- 错题自动收词
- 全真限时模考与成绩预测
- AI 学习顾问（答疑 / 错题讲解 / 学习建议）
- 学习数据深度洞察与周报月报
- 离线练习缓存与 PWA 体验增强

### 2.2 本期不包含

- 云端同步与多设备实时共享
- 用户登录 / 注册 / 鉴权
- 学习社群 / 排行榜
- 付费订阅与会员体系
- 原生移动端 App
- 实时视频 / 真人外教

## 4. 任务清单

### 任务 1：阅读与听力专项训练

**目标**：覆盖英语学习中输入型技能，提升阅读理解与听力辨音能力。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 1.1 AI 阅读理解生成 | 按目标/级别生成阅读文章 + 选择题 | 已完成 |
| 1.2 听力填空/选择 | 基于 TTS 音频的听力理解训练 | 已完成 |
| 1.3 听写全文 | 逐句听写并评分 | 已完成 |
| 1.4 transcript 同步展示 | 音频与文本对照，支持点击跳读 | 已完成 |

**验收标准**：
- 阅读文章难度与级别、目标匹配。
- 听力题目可播放标准发音，提交后给出得分与解析。
- 听写支持整句输入和相似度评分。

---

### 任务 2：词汇本与 SRS 闪卡

**目标**：将错题、生词沉淀为可复习的词汇资产，降低遗忘率。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 2.1 个人词汇本 | 用户可收藏生词/短语 | 已完成 |
| 2.2 错题自动收词 | 将错题中的原句/正确表达加入词汇本 | 已完成 |
| 2.3 间隔重复闪卡 | 基于 SM-2 复习词汇 | 已完成 |
| 2.4 词汇导入导出 | 支持 CSV/JSON 词表导入 | 已完成 |

**验收标准**：
- 用户可以手动添加/删除生词。
- 错题可一键加入词汇本。
- 闪卡复习记录下次复习日期。

---

### 任务 3：全真模考与成绩预测

**目标**：整合各题型，提供接近真实考试的限时模考与目标预测。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 3.1 完整限时模考 | 口语/写作/阅读/听力组合卷 | 待开始 |
| 3.2 自动评分与成绩预测 | 基于历史数据预测目标考试分数 | 待开始 |
| 3.3 模考历史对比 | 展示多次模考成绩变化 | 待开始 |
| 3.4 模考错题集 | 自动归档模考中的错题 | 待开始 |

**验收标准**：
- 模考包含多种题型并计时。
- 完成后给出总分、分项得分和能力变化趋势。
- 错题自动进入错题本。

---

### 任务 4：AI 学习顾问

**目标**：让用户可以随时向 AI 提问英语知识或学习建议。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 4.1 英语答疑助手 | 用户可提问英语知识点 | 待开始 |
| 4.2 学习建议生成 | 基于画像推荐每日学习重点 | 待开始 |
| 4.3 错题讲解 | 针对任意错题请求 AI 详细讲解 | 待开始 |

**验收标准**：
- 顾问能回答语法、词汇、表达等问题。
- 可针对错题给出详细讲解和类似例句。

---

### 任务 5：数据洞察与目标预测

**目标**：更强的数据洞察，帮助用户看清进步路径。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 5.1 能力趋势预测 | 预测达到目标水平所需时间 | 待开始 |
| 5.2 目标达成追踪 | 可视化当前进度距目标差距 | 待开始 |
| 5.3 周/月报自动生成 | 自动生成可导出的学习周报/月报 | 待开始 |

**验收标准**：
- Progress 页面展示目标预测线。
- 周报/月报可导出为 PDF/Word。

---

### 任务 6：离线体验增强

**目标**：让应用在弱网或无网环境下也能基本使用。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 6.1 Service Worker 后台同步 | 离线时缓存操作，联网后同步 | 待开始 |
| 6.2 离线练习包 | 预下载练习题目，无网可用 | 待开始 |
| 6.3 PWA 安装优化 | 完善 manifest、icon、启动屏 | 待开始 |

## 6. 验收标准（整体）

1. 阅读、听力、词汇、模考、AI 顾问五大模块均可正常使用。
2. 阅读与听力题目难度与用户目标和级别匹配。
3. 词汇本支持手动添加、错题自动加入、SRS 闪卡复习。
4. 全真模考支持计时、自动评分、错题归档。
5. AI 学习顾问能回答英语知识问题并讲解错题。
6. Progress 页面展示目标预测与能力趋势。
7. 离线状态下可访问已缓存的练习内容。

---

## 7. 风险与应对

| 风险 | 应对 |
|------|------|
| 阅读/听力 AI 生成质量不稳定 | 提供刷新按钮，允许用户重新生成 |
| 听力 TTS 语速/发音不适应 | 支持调节语速、重听 |
| 词汇量增长后复习负担大 | 每日复习量上限与优先级排序 |
| 模考自动评分依赖 AI | 关键题型人工复核入口 |
| 离线缓存占用存储过大 | 限制缓存题目数量与清理策略 |
