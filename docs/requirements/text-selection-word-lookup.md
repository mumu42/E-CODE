# 选中文本查词与词汇添加功能 — 需求文档

> **版本**: v1.0
> **日期**: 2026-09-24
> **状态**: 待评审

---

## 1. 功能概述

在英语学习 Web Agent 的所有页面中，用户选中英文文本后通过**右键菜单**触发弹窗，展示该文本的**中文释义、词性（含更多词性展示）、例句**等信息，并提供**语音朗读**和**添加到词汇本**的功能。

---

## 2. 目标用户场景

| 场景 | 用户操作 | 期望结果 |
|------|----------|----------|
| 阅读文章遇到生词 | 选中单词 → 右键 → 查词 | 看到释义、词性、例句 |
| 听力材料看不懂的长句 | 选中短语 → 右键 → 查词 | 看到短语释义、用法 |
| 做题时遇到不认识的词 | 选中题干中的词 → 右键 → 查词 | 快速理解词义，不影响做题流程 |
| 想把生词收藏学习 | 查词弹窗中点击"添加到词汇本" | 单词存入词汇本，后续可复习 |

---

## 3. 功能需求

### 3.1 触发方式

| 项目 | 说明 |
|------|------|
| **触发事件** | 用户选中文本后，点击**鼠标右键**（`contextmenu` 事件） |
| **选中范围** | 全文所有英文文本：题目、阅读材料、听力材料、翻译题、说明文字等 |
| **选中长度限制** | 最少 **2 个字符**，最多 **200 个字符** |
| **空选/无效选** | 未选中文本时右键保持浏览器默认右键菜单 |
| **中文选中** | 选中中文时不触发此功能（保留默认右键菜单） |

### 3.2 弹窗 UI

#### 3.2.1 位置

- 弹窗出现在鼠标右键点击位置附近
- 优先显示在选中文本**下方**
- 若下方空间不足，显示在**上方**
- 弹窗不超出浏览器视口边界

#### 3.2.2 弹窗内容

| 信息项 | 说明 | 示例 |
|--------|------|------|
| **选中文本** | 加粗显示选中的单词或短语 | **ambiguous** |
| **音标** | 显示该词的音标（若有） | /æmˈbɪɡjuəs/ |
| **词性** | 显示当前词性 | `adj.` 形容词 |
| **中文释义** | 当前选中语境下的中文释义 | 模棱两可的；不明确的 |
| **更多词性** | 显示该词的其他常见词性及释义 | `vt.` 使含糊不清（较少用） |
| **例句** | 一个英文例句及其中文翻译（与当前词性对应） | "His answer was **ambiguous**." → "他的回答模棱两可。" |
| **🔊 朗读按钮** | 点击后朗读选中的文本 | 调用浏览器 TTS |
| **➕ 添加到词汇本** | 将当前词添加到词汇本 | 调用 `addVocabulary()` |
| **加载态** | AI 查询期间显示"正在查询..." | 骨架屏或文字提示 |
| **错误态** | 查询失败时显示"查询失败，请稍后重试" | 红色提示文字 |

#### 3.2.3 关闭方式

- 点击弹窗外部区域
- 按 `Escape` 键
- 以上两种方式均关闭弹窗并清除选中状态

### 3.3 AI 查询

#### 3.3.1 接口

新建后端 API 路由：`POST /api/ai/word-lookup`

**请求体：**
```json
{
  "word": "ambiguous"
}
```

**响应体：**
```json
{
  "word": "ambiguous",
  "meaning": "模棱两可的；不明确的",
  "partOfSpeech": "adj.",
  "phonetic": "/æmˈbɪɡjuəs/",
  "otherMeanings": [
    { "partOfSpeech": "vt.", "meaning": "使含糊不清（较少用）" }
  ],
  "example": {
    "english": "His answer was ambiguous.",
    "chinese": "他的回答模棱两可。"
  }
}
```

#### 3.3.2 防抖与缓存

- **防抖**: 选中相同文本时，200ms 内不重复发起 API 请求
- **缓存**: 同一 session 内已查过的词直接返回缓存结果，不再请求 AI

#### 3.3.3 错误处理

- AI 服务异常时，弹窗显示"查询失败，请稍后重试"
- 网络错误时同上
- 失败后用户可重新选中右键重试

### 3.4 语音朗读

- 复用 `lib/tts.ts` 中的 `speak(text)` 函数
- 朗读选中的原文文本（非中文翻译）
- 若浏览器不支持 TTS，朗读按钮置灰并显示"当前浏览器不支持语音功能"
- 朗读期间按钮显示"播放中..."

### 3.5 添加到词汇本

- 调用 store 中已有的 `addVocabulary()` 方法
- 添加数据结构：
  - `word`: 选中的原文
  - `meaning`: AI 返回的中文释义
  - `example`: AI 返回的英文例句（作为 `example` 字段）
  - `source`: `"manual"`
- 添加成功后弹窗提示"已添加到词汇本"，且按钮变为"已添加"（禁用状态）

## 4. 受影响页面（无需改动）

以下页面的文本内容均可被选中触发，但**无需修改任何页面代码**：

| 页面 | 可选中文本 |
|------|-----------|
| `/reading` | 文章正文、题目、选项 |
| `/listening` | 听力原文、题目、选项、解析 |
| `/listening/dictation` | 听写结果对比 |
| `/write` | 题目、批改反馈中的例句 |
| `/speak` | 话题提示、反馈内容 |
| `/chat` | 对话内容、AI 回复 |
| `/exam/*` | 阅读/听力题目、选项、文章 |
| `/review` | 错题、解析、例句 |
| `/vocabulary` | 词汇列表项 |
| `/vocabulary/review` | 闪卡内容 |
| `/plan` | 学习计划内容 |
| `/advisor` | 顾问回复中的例句 |

## 6. 验收标准

1. 打开任一页面（阅读/听力/词汇等），选中任意英文文本 → 右键 → 弹出查词弹窗 ✅
2. 弹窗正确显示：选中文本、音标、词性、中文释义、更多词性、例句 ✅
3. 点击 🔊 按钮，浏览器朗读选中文本 ✅
4. 点击 ➕ 按钮，单词添加到词汇本 ✅
5. 添加后按钮变为"已添加"（禁用态） ✅
6. 点击弹窗外部或按 Escape 关闭弹窗 ✅
7. 选中文时右键不触发查词（保留默认右键菜单） ✅
8. 未选中文本时右键不触发查词（保留默认右键菜单） ✅
9. 选中文本过长（>200字符）时不触发 ✅
10. 重复选中同一文本时使用缓存，不重复请求 AI ✅

---

## 7. 备注

- 弹窗自带 `z-index` 设置，确保覆盖所有页面元素
- 所有 AI 提示词为英文构造，确保 AI 理解准确
- 右键查词需要阻止默认右键菜单（`e.preventDefault()`），仅在选中有文本时拦截
