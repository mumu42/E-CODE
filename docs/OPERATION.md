# English Agent 操作手册

> 更新日期：2026-08-24
> 适用范围：Phase 4 + Phase 5 M1–M5 已完成的功能

---

## 1. 快速开始

### 1.1 创建学习档案

首次打开应用会进入 Onboarding：

1. 选择学习目标（留学/学校/四六级/雅思托福等）。
2. 完成自适应英语水平测评：
   - 系统会根据你的答题正确率动态调整题目难度（A1–C2）。
   - 答对则提升难度，答错则降低难度。
   - 完成 12 道自适应题后，提交一段口语/写作样本。
   - 最终由 AI 综合判定你的 CEFR 等级。
3. 完成，进入「今日任务」。

> 一个浏览器内可以创建多个档案，数据相互隔离。

### 1.2 切换档案

点击顶部导航栏右侧齿轮图标 → 选择档案 → 切换。

## 2. 今日任务

路径：`/dashboard`

- 展示当天的推荐任务。
- 可点击卡片直接进入对应练习。

---

## 3. 口语练习

路径：`/speak`

1. 点击「换一题」生成新的话题。
2. 对着麦克风说话（或手动输入文字）。
3. 语音识别时会实时显示每个词的识别置信度：
   - 绿色：高置信度
   - 红色：低置信度，可点击 🔊 听取标准发音
4. 点击「提交」，AI 会给出：
   - 综合评分
   - 语法问题
   - 更地道表达
   - 发音提示
   - 整体反馈

### 对话模式

路径：`/chat`

- 选择角色（朋友/面试官/考官/老师/同事）。
- 和 AI 进行多轮对话，AI 会实时纠正错误。

---

## 4. 写作练习

路径：`/write`

1. 查看 AI 生成的写作题目。
2. 在输入框中写作文。
3. 点击提交，AI 给出：
   - 总分
   - 语法/词汇/结构分项得分
   - 原文高亮：错误表达在原文中以红色背景标出，鼠标悬停可查看修正和说明
   - 语法错误列表
   - 改进版本
   - 提升建议

---

## 5. 阅读训练

路径：`/reading`

1. 点击「开始阅读」，AI 生成与目标/级别匹配的文章和选择题。
2. 阅读文章，选择每道题的答案。
3. 提交后自动评分并展示解析。
4. 答错的题会自动加入错题本。

---

## 6. 听力训练

路径：`/listening`

1. 点击「开始听力」，生成听力材料。
2. 点击「播放音频」听 TTS 朗读。
3. 选择答案并提交。
4. 可点击「显示原文」查看 transcript，并逐句点击重听。

### 听写模式

路径：`/listening/dictation`

- 播放句子，输入听到的内容。
- 提交后计算相似度得分。

---

## 7. 词汇本与闪卡复习

路径：`/vocabulary`

### 7.1 添加词汇

- 手动输入单词/短语、释义、例句。
- 从错题一键加入词汇本。
- 导入 CSV/JSON 词表。

### 7.2 导入导出

- 导入：选择 CSV 或 JSON 文件。
- 导出：选择 CSV 或 JSON 格式下载。

### 7.3 闪卡复习

路径：`/vocabulary/review`

- 基于 SM-2 算法自动调度复习。
- 卡片正面显示单词，背面显示释义/例句。
- 点击「难/会/易」评定掌握程度，系统会自动计算下次复习时间。

---

## 8. 错题复习

路径：`/review`

### 8.1 今日待复习

- 列出今天需要复习的错题。
- 可切换模式：
  - **闪卡**：正面错误表达，背面正确表达和解析。
  - **听写**：播放正确句子，输入听到的内容。
  - **填空**：根据 original/correction 自动生成挖空题。
  - **每日挑战**：限时组合多种模式。

### 8.2 薄弱点分析

- 按错误类型统计，帮助定位薄弱项。

### 8.3 加入词汇本

- 任意错题可一键加入词汇本，方便后续复习。

---

## 9. 模拟考试

路径：`/exam`

### 9.1 自定义题库模考

- 选择考试类型。
- 导入 JSON/Excel 题库。
- 开始限时模考。

### 9.2 全真限时模考

路径：`/exam/full`

- 45 分钟完整考试。
- 包含阅读、听力、写作、口语四个部分。
- 客观题自动评分，写作/口语由 AI 评分。
- 完成后展示总分、分项得分、AI 反馈。
- 错题自动归档到错题本。

---

## 10. 学习进度

路径：`/progress`

### 10.1 核心统计

- 总练习次数
- 口语/写作/对话练习次数
- 平均评分
- 当前连续打卡/最长连续打卡
- 成就徽章

### 10.2 可视化

- **能力雷达图**：基于最新测评数据。
- **评分趋势**：最近 14 天练习得分趋势。
- **模考成绩趋势**：多次模考成绩变化。
- **学习热力图**：每日练习次数分布。
- **薄弱点分析**：按错误类型统计。

### 10.3 预测分数

- 基于历史模考、阅读、听力、口语、写作记录预测目标考试分数。
- 展示阅读、听力、写作、口语四项预测得分。

### 10.4 AI 学习摘要

- 点击「生成学习摘要」，AI 基于近期学习数据生成：
  - 优势
  - 待加强点
  - 下一步建议

## 11. 设置中心

路径：`/settings`

### 11.1 Prompt 自定义

- 可分别自定义口语、写作、对话、计划、测评、专项练习、摘要、阅读、听力等 Prompt。
- 支持 `{{var}}` 占位符。

### 11.2 学习提醒

- 开启/关闭每日提醒。
- 设置提醒时间。

### 11.3 键盘快捷键

- 快捷键开关。
- 支持的快捷键：
  - `Alt + D`：今日任务
  - `Alt + S`：口语
  - `Alt + W`：写作
  - `Alt + C`：对话
  - `Alt + R`：阅读
  - `Alt + L`：听力
  - `Alt + V`：词汇
  - `Alt + E`：模考
  - `Alt + P`：进度
  - `Alt + /`：设置

### 11.4 主题与语言

- 切换深色/浅色/系统主题。
- 切换界面语言（中文/英文）。

## 12. 数据管理

### 12.1 导入导出

路径：`/progress` 右上角

- **导出数据**：将当前档案全部数据打包下载为 JSON。
- **导入数据**：从 JSON 文件恢复数据。

### 12.2 自动备份

- 点击顶部导航栏齿轮图标 → 备份管理。
- 可手动触发备份或恢复。
- 若开启文件系统访问权限，可设置自动保存到本地目录。

### 12.3 多档案切换

- 同一浏览器可创建多个学习档案。
- 切换档案时，练习记录、错题、词汇本等数据完全隔离。

---

## 13. 目标预测与学习报告

### 13.1 目标达成预测

路径：`/progress`

- 系统根据最近 30 天的练习频率、平均得分、错题数估算达到目标所需的周/天数。
- 展示总体进度百分比、各项能力（听力/口语/阅读/写作/语法）当前得分与目标的差距。
- 提供每周建议练习次数。

### 13.2 学习周报/月报

路径：`/report`

- 选择查看「周报」或「月报」。
- 统计周期内展示：
  - 练习次数、平均得分
  - 新增错题、新增词汇
  - 打卡天数、模考次数、平均模考得分
  - 练习类型分布
- 支持导出为 Word 和 PDF。

## 14. 离线使用

### 14.1 离线练习包

路径：`/settings`

- 在「离线练习包」卡片中点击「下载离线练习包」。
- 缓存完成后，断网仍可访问核心页面（首页、口语、写作、对话、复习、阅读、听力、词汇、顾问、进度、计划、模考等）。
- AI 相关的生成/评分需要联网。

### 14.2 PWA 安装

- 使用 Chrome/Edge 等浏览器访问应用。
- 浏览器地址栏会提示「安装应用」，点击即可将应用安装到桌面。
- 安装后应用将以独立窗口运行，并支持离线访问已缓存页面。

### 14.3 后台同步

- Service Worker 会在联网后尝试后台同步离线期间未能完成的请求。
- 用户无需手动操作，重新联网后数据会自动同步到本地状态。

## 15. 常见问题

### Q1：AI 生成失败怎么办？

- 检查网络连接。
- 检查 `.env` 中 AI 密钥是否配置正确。
- 刷新页面或点击「换一题」重试。

### Q2：听力播放不了？

- 浏览器需要支持 Web Speech API（Chrome/Edge/Safari 现代版）。
- 检查是否授予浏览器音频播放权限。

### Q3：语音识别失败？

- 仅支持 Chrome/Edge 等支持 Web Speech API 的浏览器。
- 需要授予麦克风权限。

### Q4：数据会不会丢失？

- 数据保存在浏览器 IndexedDB 中。
- 建议定期使用「导出数据」备份到本地。
- 可开启自动保存到本地目录。
