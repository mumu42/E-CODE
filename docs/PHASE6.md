# 六期任务规划（Phase 6）

> 更新日期：2026-08-24  
> 备注：前五期已完成英语学习核心闭环（目标选择、自适应测评、听说读写、词汇、模考、AI 顾问、进度、离线）。本期进入 PRD 后续迭代方向，重点扩展真题、AI 语音对话、移动端 PWA 和多语言界面。

---

## 1. 目标

在四期、五期已有能力基础上，横向扩展更贴近真实考试与使用场景的模块：

1. **真题模拟与考试时间训练**：接入 CET/IELTS/TOEFL 真题库，按真实考试时间倒计时。
2. **AI 语音对话陪练**：实时语音对话、AI 发音示范/纠音、角色扮演。
3. **移动端与 PWA 深化**：原生 App 壳、推送通知、应用商店发布。
4. **多语言界面完整翻译**：英文 UI 完整覆盖、国际化文案管理。

---

## 2. 范围边界

### 2.1 本期包含

- 真题题库接入与真题模考
- 考试时间训练模式
- 实时语音对话（WebRTC / Web Speech）
- AI 语音陪练角色
- Capacitor / PWA 打包
- 推送通知
- 英文 UI 完整翻译
- 国际化（i18n）文案管理

### 2.2 本期不包含

- 云端同步与多设备实时共享
- 用户登录 / 注册 / 鉴权
- 学习社群 / 排行榜
- 付费订阅与会员体系
- 实时视频 / 真人外教

## 4. 任务清单

### 任务 1：真题模拟与考试时间训练

**目标**：提供接近真实考试的限时真题训练。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 1.1 真题题库数据结构 | 设计 `ExamQuestion` 扩展支持真题来源、年份、考试类型 | 待开始 |
| 1.2 真题导入工具 | 支持 JSON/Excel 批量导入真题 | 待开始 |
| 1.3 真题模考页面 | 新增 `/exam/real` 按真实考试时间倒计时 | 待开始 |
| 1.4 专项真题训练 | 按考试类型/年份/题型筛选练习 | 待开始 |

**验收标准**：
- 可导入并展示 CET/IELTS/TOEFL 真题。
- 真题模考按考试时间倒计时并自动交卷。
- 专项训练支持按条件筛选真题。

---

### 任务 2：AI 语音对话陪练

**目标**：让用户可以和 AI 进行实时语音对话，并获得发音和语法纠音。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 2.1 语音对话组件 | 基于 Web Speech API 实时语音输入/输出 | 待开始 |
| 2.2 AI 语音回复 | 使用 TTS 播放 AI 回复 | 待开始 |
| 2.3 发音纠音 | 对比用户语音与标准发音，标记问题 | 待开始 |
| 2.4 角色扮演场景 | 新增面试、机场、餐厅等场景角色 | 待开始 |

**验收标准**：
- 用户可通过语音与 AI 对话，AI 语音回复。
- 对话结束后展示语法和发音纠正。
- 支持多个真实场景角色。

---

### 任务 3：移动端与 PWA 深化

**目标**：将 Web 应用打包为可安装的移动应用，并支持推送通知。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 3.1 Capacitor 集成 | 初始化 Capacitor 项目配置 | 待开始 |
| 3.2 移动端适配优化 | 底部导航、触摸反馈、字体适配 | 待开始 |
| 3.3 推送通知 | 使用 FCM / APNs 实现本地通知 | 待开始 |
| 3.4 应用图标与启动屏 | 生成各平台图标和 Splash | 待开始 |

**验收标准**：
- `npm run build` 后可通过 Capacitor 构建 iOS/Android 项目。
- PWA 可安装，移动端体验良好。
- 学习提醒可推送本地通知。

---

### 任务 4：多语言界面完整翻译

**目标**：英文 UI 完整覆盖，支持中英文切换。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 4.1 文案提取 | 将硬编码中文提取到 i18n 资源文件 | 待开始 |
| 4.2 英文翻译 | 提供完整英文翻译 | 待开始 |
| 4.3 语言切换 | 设置中心支持切换界面语言 | 待开始 |
| 4.4 日期/数字本地化 | 日期、数字、得分格式本地化 | 待开始 |

**验收标准**：
- 所有页面文案均来自 i18n 资源。
- 切换语言后界面完整显示英文。
- 日期、数字格式随语言变化。

## 6. 验收标准（整体）

1. 可导入真题并进行限时真题模考。
2. AI 语音陪练可进行实时语音对话并纠音。
3. 移动端 PWA / Capacitor 可正常安装运行。
4. 界面支持中英文切换且英文覆盖完整。
5. `npm run lint` 和 `npm run build` 通过。

---

## 7. 风险与应对

| 风险 | 应对 |
|------|------|
| 真题版权/来源问题 | 使用公开样题或用户自行导入 |
| 实时语音延迟高 | 使用本地 Web Speech， fallback 文本输入 |
| Capacitor 构建复杂 | 优先 Android，iOS 作为后续补充 |
| 多语言文案遗漏 | 使用 t() 扫描工具兜底检查 |
