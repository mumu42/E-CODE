# 四期任务规划（Phase 4）

> 更新日期：2026-08-17
> 备注：本次已将二期、三期已完成并延续到四期的能力标记为已完成，避免重复规划。

---

## 1. 目标

在三期已完成的多档案、数据持久化、AI 学习规划、模考、多语言、错题 PWA 等能力基础上，进一步提升英语学习 Web Agent 的智能化、个性化与易用性，打造更完整的“本地私有 AI 学习闭环”：

1. **AI 长期记忆与个性化反馈**：让 AI 能基于用户历史练习、薄弱点和偏好，给出更连续、更贴身的辅导。
2. **内容与题库扩展**：支持更丰富的练习素材、自定义话题和本地题库导入，提升练习多样性。
3. **听说能力深度训练**：引入 TTS 发音示范、跟读评分、语音输入增强，强化口语训练效果。
4. **学习报告与数据洞察**：支持导出 Word/PDF 学习报告、学习打卡、连续学习天数等激励机制。
5. **复习系统游戏化**：闪卡、听写、填空等多种错题复习形式，提升复习趣味性。
6. **本地文件与导入导出增强**：支持目录授权、自动保存到本地文件夹、批量导入历史文件。
7. **设置与可定制性**：自定义 Prompt、学习提醒、每日推送、键盘快捷键等高级设置。

---

## 2. 范围边界

### 2.1 本期包含

- AI 长期记忆 / 学习画像
- 自定义话题 / 本地题库导入
- TTS 发音示范与跟读评分
- 学习报告导出（Word / PDF）
- 学习打卡与连续学习天数

- 闪卡、听写、填空等错题复习模式
- 本地文件夹授权与自动保存
- 设置中心（Prompt、提醒、快捷键）

### 2.2 本期不包含

- 用户登录 / 注册 / 鉴权
- 云端同步与多设备数据共享
- 学习社群 / 排行榜
- 付费订阅与会员体系
- 原生移动端 App
- 实时视频通话
- AI 真人外教

## 3. 需求变更记录

| 变更项 | 三期状态 | 四期计划 |
|--------|----------|----------|

## 4. 任务清单

### 任务 1：AI 长期记忆与学习画像

**目标**：让 AI 能够记住用户的学习偏好、历史薄弱点和进步轨迹，提供连续的个性化反馈。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 1.1 学习画像模型 | 基于历史练习、错题、测评构建 `LearningProfile` 画像 | 已完成 |
| 1.2 AI 记忆上下文 | 调用 AI 时携带近期练习摘要和薄弱点统计 | 已完成 |
| 1.3 个性化提示注入 | 在口语 / 写作 / 对话 Prompt 中注入学习画像 | 已完成 |
| 1.4 进步追踪摘要 | 每周/每月生成学习进展摘要 | 已完成 |

**验收标准**：

- AI 反馈能引用用户过往常见错误，给出“你经常混淆...”式建议。
- 同一用户在多次练习中感受到反馈越来越贴合自身水平。
- 每周自动生成一次学习小结。

---

### 任务 2：内容与题库扩展

**目标**：支持更灵活的练习素材来源，允许用户导入和管理自己的话题/题库。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 2.1 自定义话题库 | 用户可新增/编辑/收藏练习话题 | 已完成 |
| 2.2 本地题库导入 | 支持 JSON / Excel 格式导入题库 | 已完成 |
| 2.3 题库分类与标签 | 按目标/级别/题型对题库分类 | 已完成 |
| 2.4 话题推荐引擎 | 基于目标和历史记录推荐话题 | 已完成 |

**验收标准**：

- 用户可以导入 JSON / Excel 题库并在练习中使用。
- 系统能根据用户目标推荐合适话题。
- 收藏的话题可在“我的话题”中管理。

---

### 任务 3：听说能力深度训练

**目标**：通过 TTS 和跟读评分，提升用户发音和口语流利度。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 3.1 TTS 发音示范 | 对练习文本和例句提供标准发音播放 | 已完成 |
| 3.2 跟读模式 | 用户跟读例句，系统比对语音与文本 | 已完成 |
| 3.3 发音评分 | 基于识别结果给出发音准确度评分 | 已完成 |
| 3.4 语音输入增强 | 支持口语练习中语音 / 键盘输入切换 | 已完成 |

**验收标准**：

- 用户可以点击播放标准发音。
- 跟读模式能给出“高/中/低”匹配度反馈。
- 语音输入在桌面和移动端均可正常使用。

---

### 任务 4：学习报告与数据洞察

**目标**：让用户能导出精美的学习报告，并建立持续学习的正向激励。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 4.1 学习打卡 | 每日首次练习后自动打卡 | 已完成 |
| 4.2 连续学习天数 | 统计并展示连续打卡天数 | 已完成 |
| 4.3 成就徽章 | 达成特定目标后解锁徽章 | 已完成 |
| 4.4 Word 报告导出 | 生成包含练习记录、错题、进步曲线的 Word 报告 | 已完成 |
| 4.5 PDF 报告导出 | 生成 PDF 格式学习报告 | 已完成 |

**验收标准**：

- Dashboard 展示连续学习天数和徽章。
- 用户可导出 Word / PDF 学习报告。
- 报告包含练习统计、错题分析和能力变化趋势。

---

### 任务 5：错题复习游戏化

**目标**：通过多样化复习形式降低复习枯燥感，提高记忆效率。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 5.1 闪卡模式 | 正面原句/错误，背面修正/解析 | 已完成 |
| 5.2 听写模式 | 播放标准发音，用户输入正确句子 | 已完成 |
| 5.3 填空模式 | 在句子中挖空让用户补全正确表达 | 已完成 |
| 5.4 错题挑战 | 每日错题闯关 / 计时挑战 | 已完成 |

**验收标准**：

- 错题本支持闪卡、听写、填空三种复习模式。
- 每种模式都能正确记录复习结果并更新 SM-2 调度。
- 完成挑战后给予即时反馈。

---

### 任务 6：本地文件与导入导出增强

**目标**：让本地数据管理更自动化，减少用户手动操作。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 6.1 目录授权读写 | 使用 File System Access API 授权本地文件夹 | 已完成 |
| 6.2 自动保存到目录 | 每次状态变化后自动写入授权目录 | 已完成 |
| 6.3 批量导入历史文件 | 支持选择多个历史文件批量恢复 | 已完成 |
| 6.4 数据压缩归档 | 导出时可选压缩为 ZIP | 已完成 |

**验收标准**：

- Chrome / Edge 下可授权一个文件夹作为自动保存目录。
- 自动保存不影响其他浏览器的基础使用。
- 批量导入时自动去重并合并数据。

---

### 任务 7：设置中心与可定制性

**目标**：为高级用户提供更多自定义选项，提升使用效率。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 7.1 自定义 Prompt | 允许用户编辑口语/写作/对话 Prompt 模板 | 已完成 |
| 7.2 学习提醒 | PWA 通知提醒每日学习 | 已完成 |
| 7.3 键盘快捷键 | 为常用操作设置快捷键 | 已完成 |
| 7.4 数据迁移工具 | 导出旧格式并导入新格式 | 已完成 |

**验收标准**：

- 设置页面提供 Prompt 编辑器。
- 用户可开启/关闭每日学习提醒。
- 快捷键不与其他浏览器快捷键冲突。

## 6. 验收标准（整体）

1. AI 反馈能体现对用户历史错误和偏好的记忆。
2. 用户可导入自定义题库并在练习中正常使用。
3. 口语练习支持 TTS 发音示范和跟读评分。
4. Dashboard 展示连续学习天数和成就徽章。
5. 用户可导出 Word / PDF 学习报告。
6. 错题本支持闪卡、听写、填空三种复习模式。
7. Chrome / Edge 支持本地文件夹授权与自动保存。
8. 设置中心支持自定义 Prompt、学习提醒和快捷键。

---

## 7. 风险与应对

| 风险 | 应对 |
|------|------|
| File System Access API 浏览器兼容性差 | 仅作为增强功能，基础导入导出保留 |
| TTS / 语音识别在移动端不稳定 | 提供降级方案（文本输入、预加载音频） |
| 自定义 Prompt 被滥用导致输出不可控 | 提供模板变量校验和恢复默认功能 |
| PDF 报告生成体积大 | 分页导出，避免一次生成过长报告 |
| AI 长期记忆导致 Prompt 过长 | 控制历史摘要长度，仅注入关键信息 |
