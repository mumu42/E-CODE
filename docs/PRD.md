# 英语学习 Web Agent 产品需求文档（PRD）

---

## 1. 项目概述

### 1.1 产品名称
**英语学习 Web Agent**

### 1.2 产品定位
一个面向升学考试、出国留学、四六级、雅思托福人群的 AI 驱动英语学习平台。通过级别测定、个性化每日口语/写作练习、AI 实时纠错，帮助用户高效提升英语能力。

### 1.3 产品目标
- 让用户在 5 分钟内完成学习目标设定与英语水平测定。
- 根据用户目标与级别，每日推送适合的口语与写作练习。
- 利用 AI 实现口语表达纠错与写作语法纠错，提供即时、可执行的改进建议。
- 记录学习轨迹，帮助用户持续追踪进步。

---

## 2. 目标用户

| 用户群体 | 核心诉求 | 典型场景 |
|----------|----------|----------|
| **升学考试** | 提升中考/高考英语成绩 | 词汇、语法、写作训练 |
| **出国留学** | 适应海外学习与生活场景 | 面试、日常对话、学术写作 |
| **四六级考生** | 通过/高分通过 CET-4/6 | 听力、写作、翻译练习 |
| **雅思/托福考生** | 冲刺目标分数 | 口语 Part 1/2/3、独立/综合写作 |

## 3. 功能需求

### 3.1 用户目标选择
- **入口**：首次访问 / Onboarding 流程。
- **功能**：
  - 用户从四个目标中选择一个：升学考试、出国留学、四六级、雅思托福。
  - 不同目标对应不同的练习场景、题库难度、评分标准。
- **验收标准**：用户选择后，后续练习内容与推荐策略随目标变化而变化。

### 3.2 英语级别测定
- **入口**：Onboarding 流程 / 个人设置中可重新测评。
- **功能**：
  - 通过一套自适应测试题（词汇、语法、阅读）快速评估用户水平。
  - 支持用户提交一段口语/写作样本，由 AI 辅助判定实际表达能力。
  - 输出：对应 CEFR 等级（A1-C2）或目标考试对应分数区间。
- **验收标准**：
  - 测评完成后，系统给出明确级别。
  - 后续练习难度与该级别匹配。

### 3.3 每日口语练习
- **入口**：Dashboard / 每日任务 / 独立练习页。
- **功能**：
  - 系统每日根据用户目标与级别生成一个练习话题/场景。
  - 不同目标人群对应不同场景：
    - 升学考试：校园生活、图片描述、简单问答
    - 出国留学：机场、租房、课堂讨论、面试
    - 四六级：常见话题、社会热点、校园生活
    - 雅思托福：Part 2 描述、独立口语、学术讨论
  - 用户通过语音输入回答问题。
  - 系统识别语音并转换为文本，再由 AI 进行反馈。
- **验收标准**：
  - 每日话题不重复。
  - 语音识别可正常使用（基于 Web Speech API）。
  - AI 反馈包含：语法纠错、表达优化、发音建议、综合评分。

### 3.4 发音纠错
- **入口**：口语练习流程中。
- **功能**：
  - 基于语音识别结果与置信度，标记可能的发音问题。
  - 提供正确发音示范（TTS 播放）。
  - 针对常见错误给出针对性练习建议。
- **验收标准**：
  - 对识别置信度低或明显语法/搭配错误的部分给出提示。
  - 用户可以点击播放标准发音。

### 3.5 写作练习
- **入口**：Dashboard / 每日任务 / 独立练习页。
- **功能**：
  - 系统根据用户目标与级别生成写作题目。
  - 不同目标人群对应不同题型：
    - 升学考试：看图写话、短文写作
    - 出国留学：申请文书、邮件写作
    - 四六级：议论文、图表作文
    - 雅思托福：Task 2 / 独立写作、综合写作
  - 用户在线写作并提交。
  - AI 批改：语法纠错、词汇升级、结构评分、总分与改进建议。
- **验收标准**：
  - 题目与目标、级别匹配。
  - AI 批改结果清晰展示，错误项可定位到具体句子。
  - 提供修改后的参考范文或优化建议。

### 3.6 语法纠错
- **入口**：写作练习、口语练习结果页。
- **功能**：
  - 自动识别用户输入中的语法错误。
  - 标注错误类型（时态、主谓一致、冠词、从句等）。
  - 给出正确表达和简要解释。
- **验收标准**：
  - 常见语法错误识别率高于 80%。
  - 纠错结果以清晰方式展示（如高亮、下划线、卡片说明）。

### 3.7 学习进度追踪
- **入口**：Progress 页面 / Dashboard 概览。
- **功能**：
  - 展示连续学习天数、练习次数、能力雷达图。
  - 记录历史练习与 AI 反馈。
  - 展示级别提升趋势。
- **验收标准**：
  - 用户可查看过往练习记录。
  - 数据可视化清晰、直观。

## 4. 非功能需求

### 4.1 性能
- 页面首屏加载时间 < 3 秒。
- AI 批改接口响应时间 < 5 秒（简单反馈）。

### 4.2 可用性
- 支持中文界面。
- 响应式布局，适配桌面与移动端。
- 对新用户有清晰的 Onboarding 引导。

### 4.3 安全与隐私
- 用户练习数据与个人信息安全存储。
- AI 接口调用符合相关服务条款。

### 4.4 可扩展性
- 题库、场景、难度体系可扩展。
- 后续可接入第三方登录、付费订阅、学习社群等功能。

## 5. 用户流程

### 5.1 首次使用流程
```
访问首页 → 点击开始学习 → 选择学习目标
   → 完成级别测定 → 进入 Dashboard
   → 开始今日口语/写作练习 → 查看 AI 反馈
```

### 5.2 日常练习流程
```
登录 → 进入 Dashboard → 查看今日任务
   → 完成口语练习 → 查看发音/表达纠错
   → 完成写作练习 → 查看语法/结构批改
   → 查看 Progress 了解进步
```

## 6. 数据需求（本地文件存储）

本产品为**本地优先、完全私有**的 Web Agent，不依赖任何数据库或服务器端存储。用户学习数据以本地文件形式保存在用户设备中，Web Agent 支持读取这些本地文件以恢复历史学习记录。

### 6.1 数据读写方式

#### 6.1.1 写入：导出本地文件
- 用户完成测评或练习后，可点击“导出学习记录”按钮。
- 系统生成 `.xlsx` 或 `.docx` 文件，用户保存到本地任意位置。

#### 6.1.2 读取：导入本地文件
- 用户点击“导入历史记录”按钮，打开系统文件选择器。
- 选择某一天的学习文件（如 `english-agent-sessions-2026-08-03.xlsx`）后，Web Agent 在浏览器内解析并恢复数据。
- 恢复后可在 Dashboard / Progress 中查看该日期的学习记录。

### 6.2 浏览器读取本地文件方案

| 方案 | 实现方式 | 优点 | 缺点 |
|------|----------|------|------|
| **系统文件选择器（推荐）** | `showOpenFilePicker` API 或 `<input type="file">` | 通用、安全、用户可控 | 每次都需要用户手动选择文件 |
| **拖拽导入** | 监听 `dragenter/drop` 事件 | 体验好、批量导入方便 | 仍需用户主动拖拽 |
| **自动同步文件夹** | File System Access API + `showDirectoryPicker` | 可选中一个文件夹持续读取 | 仅 Chrome/Edge 支持，需用户授权 |

### 6.3 文件解析能力

| 文件类型 | 解析库 | 用途 |
|----------|--------|------|
| `.xlsx` | `xlsx` | 读取结构化学习记录、测评数据 |
| `.docx` | `mammoth` / `docx` | 读取学习报告内容 |
| `.json` | 原生 JSON.parse | 内部状态备份与恢复 |

### 6.4 数据存储原则
- **不上传**：用户的练习内容、测评结果、AI 反馈等不上传到任何服务器。
- **本地文件为主**：数据以 Excel（.xlsx）或 Word（.docx）文件形式导出保存。
- **浏览器临时状态**：运行期间使用浏览器 `localStorage` / `IndexedDB` 临时存储当前会话数据，关闭页面前可导出为本地文件。
- **导入/导出**：用户可随时导出学习记录，也可导入历史文件恢复学习进度。

### 6.5 本地文件格式建议

#### 方案 A：Excel（推荐）
- **用户档案表**（profile）：email、目标人群、当前级别、测评历史
- **练习记录表**（sessions）：时间、类型、题目、用户输入、AI 反馈、各项评分
- **测评记录表**（assessments）：时间、各维度得分、最终评级

Excel 优势：结构清晰、方便查看和统计、用户熟悉。

#### 方案 B：Word
- 更适合生成“学习报告”式的导出内容，如每日练习总结、作文批改详情、口语练习完整记录。
- 可作为 Excel 的补充，用于生成可视化的练习报告文档。

### 6.6 运行时数据结构

```typescript
interface UserProfile {
  email?: string;
  target: "SCHOOL" | "STUDY_ABROAD" | "CET" | "IELTS_TOEFL";
  level: "A1" | "A2" | "B1" | "B2" | "C1" | "C2";
  createdAt: string;
  updatedAt: string;
}

interface AssessmentRecord {
  id: string;
  date: string;
  scores: {
    listening?: number;
    speaking?: number;
    reading?: number;
    writing?: number;
    grammar?: number;
  };
  level: string;
}

interface PracticeRecord {
  id: string;
  type: "SPEAK" | "WRITE";
  date: string;
  topic: string;
  scenario: string;
  userInput: string;
  aiFeedback: string;
  grammarScore?: number;
  fluencyScore?: number;
}
```

### 6.7 文件命名规范
- `english-agent-profile-{date}.xlsx` — 用户档案与测评记录
- `english-agent-sessions-{date}.xlsx` — 练习记录
- `english-agent-report-{date}.docx` — 学习报告

## 9. 风险与假设

| 风险 | 应对措施 |
|------|----------|
| Web Speech API 浏览器兼容性 | 提供降级方案（文字输入代替语音） |
| AI 批改成本 | 使用提示词优化，限制单次请求长度 |
| 语音识别准确率影响纠错效果 | 明确提示用户尽量清晰发音，AI 反馈以文本为基础 |
| 不同目标人群题目难度把控 | 建立分级题库和 Prompt 模板 |
| 本地文件丢失或误删 | 提供导出提醒、支持备份多个历史文件 |
| 浏览器 localStorage 数据清理 | 重要数据及时导出为 Excel/Word；关闭页面前提示保存 |
