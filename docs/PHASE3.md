# 三期任务规划（Phase 3）

> 更新日期：2026-08-10

---

## 1. 目标

在二期核心练习能力的基础上，进一步补齐本地化英语学习 Web Agent 的长期学习闭环：

1. 支持在同一浏览器内管理多个本地学习档案，满足家庭/多用户共用场景。
2. 强化本地数据持久化能力，实现自动备份、版本回滚和一键恢复。
3. 引入真题模拟考试时间训练，支持限时模考和成绩分析。
4. 上线本地 AI 学习规划师，根据目标、水平和薄弱点动态生成学习计划。
5. 支持中英文界面切换，提升多语言使用体验。
6. 增强错题本与薄弱点训练，引入间隔重复复习机制。
7. 优化移动端体验和 PWA 离线能力，让本地使用更顺滑。

---

## 2. 范围边界

### 2.1 本期包含

- 本地多档案管理（同一浏览器内切换）
- 本地数据持久化增强（IndexedDB / static 文件 / 自动备份）
- 真题库与模拟考试时间训练
- AI 学习规划师（长期计划生成 + 每日任务推荐）
- 多语言界面（中文 / 英文）
- 错题本与薄弱点专项训练增强
- PWA 与移动端适配

### 2.2 本期不包含

- 用户登录 / 注册 / 鉴权
- 云端同步与多设备数据共享
- 学习社群 / 排行榜
- 付费订阅与会员体系
- 原生移动端 App
- 实时视频通话
- AI 真人外教

## 4. 任务清单

### 任务 1：本地多档案管理

**目标**：在同一浏览器内支持多个学习档案，方便家庭或多用户共用一台设备。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 1.1 档案数据模型 | 定义 `Profile`，包含昵称、目标、级别、创建时间等 | 待开始 |
| 1.2 档案切换 UI | 在设置或顶部栏展示当前档案，支持新增/切换/删除 | 待开始 |
| 1.3 档案隔离 | 每个档案拥有独立的练习记录、错题本、计划 | 待开始 |
| 1.4 默认档案 | 首次打开时自动创建默认档案 | 待开始 |

**验收标准**：

- 用户可以在不登录的情况下创建多个学习档案。
- 切换档案后，数据完全隔离。
- 删除档案时有确认提示。

---

### 任务 2：本地数据持久化增强

**目标**：让学习数据在本地更可靠，支持自动备份和恢复。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 2.1 IndexedDB 存储 | 将 Zustand store 持久化到 IndexedDB | 待开始 |
| 2.2 自动备份到 static | 每次练习/测评后自动导出 JSON 到 `static/` | 待开始 |
| 2.3 版本回滚 | 保留最近 N 份备份，支持恢复到某一版本 | 待开始 |
| 2.4 导入/导出增强 | 支持完整数据包导入导出 | 待开始 |
| 2.5 数据完整性校验 | 导入时校验格式和版本 | 待开始 |

**验收标准**：

- 刷新页面后数据不丢失。
- `static/` 下自动生成带时间戳的备份文件。
- 用户能选择历史备份进行恢复。
- 导入时错误数据给出明确提示。

---

### 任务 3：真题模拟考试时间训练

**目标**：提供接近真实考试的限时训练环境。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 3.1 真题题库 | 雅思 / 托福 / 四六级 / 考研真题录入或用户上传 | 待开始 |
| 3.2 考试模式 | 限时、分段计时、不可返回 | 待开始 |
| 3.3 分项模考 | 听力、阅读、写作、口语单独模考 | 待开始 |
| 3.4 自动阅卷 | 客观题自动评分，主观题 AI 批改 | 待开始 |
| 3.5 成绩报告 | 总分、分项得分、用时分析、能力变化 | 待开始 |

**验收标准**：

- 用户能选择真题进行限时模考。
- 考试结束后生成详细的成绩报告。
- 模考记录保存并纳入 Progress 分析。

---

### 任务 4：AI 学习规划师

**目标**：根据用户目标、水平和薄弱点，自动生成并动态调整长期学习计划。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 4.1 规划师 Prompt | 输入目标、级别、可用时间、弱项，输出长期计划 | 待开始 |
| 4.2 计划生成 API | `/api/ai/plan`：生成周/月学习计划 | 待开始 |
| 4.3 每日任务推荐 | 首页展示今日推荐任务 | 待开始 |
| 4.4 进度追踪 | 根据完成情况动态调整后续计划 | 待开始 |
| 4.5 本地提醒 | 基于浏览器通知的学习/复习提醒 | 待开始 |

**验收标准**：

- 用户能根据目标获得个性化学习计划。
- 每日任务根据完成进度动态调整。
- 计划内容可编辑和跳过。

---

### 任务 5：多语言界面

**目标**：支持中英文界面切换，服务更广泛的用户群体。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 5.1 i18n 框架 | 接入 `next-intl` 或同类方案 | 待开始 |
| 5.2 文案提取 | 将页面文案抽离为语言包 | 待开始 |
| 5.3 语言切换 | 设置页支持中英文切换 | 待开始 |
| 5.4 日期/数字本地化 | 时间、分数、日期格式本地化 | 待开始 |
| 5.5 AI 回复语言 | 根据界面语言切换 AI 默认回复语言 | 待开始 |

**验收标准**：

- 切换语言后，页面文案即时更新。
- 日期、数字格式符合对应语言习惯。
- AI 默认回复语言与界面语言一致。

---

### 任务 6：错题本与薄弱点训练增强

**目标**：基于历史错误数据，提供更智能的复习和专项训练。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 6.1 错题自动收录 | AI 批改结果自动加入错题本 | 待开始 |
| 6.2 错题分类 | 按语法、词汇、发音等标签分类 | 待开始 |
| 6.3 间隔重复算法 | 类 Anki 的复习调度 | 待开始 |
| 6.4 专项练习生成 | 针对错题类型自动生成类似题目 | 待开始 |
| 6.5 错题掌握度 | 记录错题复习次数和掌握程度 | 待开始 |

**验收标准**：

- 练习和批改中的错误自动进入错题本。
- 系统根据掌握度推送需要复习的错题。
- 专项练习能命中用户薄弱点。

---

### 任务 7：PWA 与移动端适配

**目标**：提升移动端体验，让 Web 应用更接近原生应用。

| 子任务 | 说明 | 状态 |
|--------|------|------|
| 7.1 响应式优化 | 所有核心页面适配移动端 | 待开始 |
| 7.2 Service Worker | 离线缓存核心资源 | 待开始 |
| 7.3 Web App Manifest | 支持添加到主屏幕 | 待开始 |
| 7.4 录音优化 | 移动端麦克风权限和录制体验优化 | 待开始 |
| 7.5 本地提醒 | 基于浏览器通知的学习提醒 | 待开始 |

**验收标准**：

- 手机浏览器访问主要流程无体验障碍。
- 支持添加到桌面。
- 离线时能访问已缓存页面。

## 8. 风险与应对

| 风险 | 应对措施 |
|------|----------|
| IndexedDB 容量限制 | 定期导出到 `static/`，大文件做分片处理 |
| 真题版权问题 | 优先使用公开真题/模拟题，或引导用户上传 |
| 多语言翻译维护成本高 | 先支持中英文，关键路径优先覆盖 |
| 浏览器本地存储被清除 | 默认自动备份到 `static/`，并提供手动导出入口 |
| 移动端录音兼容性 | 提供文字输入降级方案，针对主流浏览器测试 |
| PWA 离线体验复杂 | 先缓存静态资源，复杂动态内容逐步支持 |
